# 5. Experimental & Raw

| Core | Potential modifiers |
| ---- | ------------------- |
| Brutalism | Raw, Industrial, Monochrome, Colorful, Newspaper |
| Neo-Brutalism | Pastel, Acid, Corporate, Playful, 3D |
| Anti-Design | Distorted, Chaotic, Glitch, Asymmetric, Ugly |
| Maximalism | Colorful, Patterned, Collage, Typography, 3D |
| Deconstructed | Broken Grid, Overlap, Typography, Asymmetric |
| Organic Brutalism | Natural, Earthy, Soft, Hand-Drawn |
| Chaotic UI | Glitch, Distortion, Randomized, Experimental |

Guidance: thick borders, hard shadows, broken grids allowed. Neo-Brutalism = brutalist structure + playful pastel/3D. Anti-Design/Chaotic intentionally uncomfortable — use only for artistic briefs.
