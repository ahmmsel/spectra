# 13. Gaming & Interactive

| Core | Potential modifiers |
| ---- | ------------------- |
| Gaming UI | RGB, Dark, Neon, HUD |
| RPG UI | Fantasy, Medieval, Magical, Inventory |
| Sci-Fi Gaming | HUD, Holographic, Cyberpunk |
| Arcade UI | Pixel, CRT, Neon, Retro |
| Fantasy UI | Medieval, Magical, Gothic, Illustrated |
| Esports UI | Aggressive, Neon, Dark, Dynamic |

Guidance: HUD frames, inventory/card patterns, glow + motion feedback. Esports = aggressive angles + dynamic type; RPG/Fantasy = illustrated panels + serif/fantasy type.
