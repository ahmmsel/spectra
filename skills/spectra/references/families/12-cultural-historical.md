# 12. Cultural & Historical

| Core | Potential modifiers |
| ---- | ------------------- |
| Art Nouveau | Botanical, Decorative, Vintage, Organic |
| Art Deco | Luxury, Geometric, Gold, Black |
| Bauhaus | Geometric, Primary Colors, Functional |
| Constructivism | Red, Black, Typography, Geometry |
| Mid-Century Modern | Warm, Furniture, Geometric, Retro |
| Japanese Minimalism | Zen, Natural, Paper, Monochrome |
| Ukiyo-e Inspired | Woodblock, Japanese, Vintage, Illustration |
| Postmodernism | Memphis, Colorful, Asymmetric, Experimental |

Guidance: honor the era's geometry/ornament. Constructivism = red/black diagonals + heavy type; Nouveau = botanical curves; Japanese Minimalism = zen whitespace + paper texture.
