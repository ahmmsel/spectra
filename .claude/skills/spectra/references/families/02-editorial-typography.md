# 2. Editorial & Typography

| Core | Potential modifiers |
| ---- | ------------------- |
| Editorial | Fashion, Luxury, Modern, Experimental, Minimal |
| Magazine | Dense Grid, Image-Heavy, Bold Headlines, Collage |
| Newspaper | Classic, Modern, Monochrome, Breaking-News, Dense |
| Fashion Editorial | Luxury, Photography, Serif, High Contrast, Art Direction |
| Typography-First | Oversized Type, Kinetic, Experimental, Monospace, Serif |
| Poster / Swiss Poster | Bold Type, Geometric, Color Blocking, Minimal |
| Art Direction | Experimental, Cinematic, Photography, Collage |

Guidance: type leads, images second. Oversized headlines, drop caps/pull quotes for editorial, dense multi-column for magazine/newspaper, full-bleed photography for fashion.
