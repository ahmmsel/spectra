# 1. Minimal & Modern

| Core | Potential modifiers |
| ---- | ------------------- |
| Minimalism | Monochrome, Warm, Cool, Editorial, Soft, High-Contrast, Luxury |
| Swiss / International | Red Accent, Monochrome, Grid-Heavy, Typographic, Experimental |
| Modernist | Geometric, Monochrome, Bold Typography, Architectural |
| Bauhaus | Primary Colors, Geometric, Experimental Grid, Industrial |
| Functionalism | Utility, Dense, Technical, Monochrome, Data-Driven |
| Flat Design | Colorful, Corporate, Playful, Minimal, Illustrative |
| Flat 2.0 | Soft Shadows, Gradient, Depth, Glass, Colorful |
| Monochrome | Black & White, Warm Gray, Cool Gray, Single Accent, High Contrast |

Guidance: strict grids, whitespace, one accent max. Swiss = asymmetric 12-col grid, Helvetica/Inter/Grotesk, tabular numerals. Modifiers only shift palette/temperature/contrast.
