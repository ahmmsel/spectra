# 4. Glass & Translucent

| Core | Potential modifiers |
| ---- | ------------------- |
| Glassmorphism | Frosted, Dark Glass, Colorful, Aurora, Crystal |
| Liquid Glass | Fluid, Clear, Iridescent, Dark, Metallic |
| Spatial UI | Floating, Immersive, Minimal, Glass, 3D |

Note: keep Crystal / Translucent / Holographic as modifiers of the cores above, not independent systems, unless a recipe demands otherwise. Modifiers: Transparent, Faceted, Iridescent, Luxury, Soft, Dark, Colorful, Layered, Rainbow, Chrome, Neon, Futuristic.

Guidance: backdrop-blur, translucency, layered depth. Dark Glass for dashboards, Aurora/Colorful for marketing, Spatial floating panels for immersive.
