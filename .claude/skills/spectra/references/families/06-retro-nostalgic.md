# 6. Retro & Nostalgic

| Core | Potential modifiers |
| ---- | ------------------- |
| Y2K | Chrome, Bubble, Cyber, Pink, Tech |
| Web 1.0 | Geocities, Pixel, HTML, Windows, Personal |
| Web 2.0 | Glossy, Gradient, Rounded, Reflections, Corporate |
| Frutiger Aero | Nature, Water, Sky, Glossy, 3D |
| Vaporwave | Neon, Sunset, Grid, Chrome, Glitch |
| Retro Futurism | Space Age, Chrome, Atomic, Mid-Century |
| Pixel Art | 8-Bit, Arcade, RPG, Gameboy, Terminal |
| Arcade | Neon, CRT, Pixel, Gaming, Retro |
| Windows Classic | 95, 98, XP, Desktop, Utility |
| Macintosh Classic | Mac OS, Pixel, Monochrome, Desktop |

Guidance: commit to one era. CRT/scanlines for arcade/terminal, gloss/reflections for Web 2.0, chrome/bubbles for Y2K. Pixel cores use stepped type + sprite imagery.
