# 8. Playful & Expressive

| Core | Potential modifiers |
| ---- | ------------------- |
| Memphis | Pastel, Neon, Geometric, 80s, Minimal |
| Pop Art | Comic, Halftone, Primary Colors, Vintage |
| Hand-Drawn | Sketch, Marker, Pencil, Doodle, Notebook |
| Comic UI | Speech Bubbles, Halftone, Manga, Pop Art |
| Sticker UI | Cute, 3D, Y2K, Colorful, Hand-Drawn |
| Collage | Magazine, Photography, Handmade, Experimental |
| Doodle | Educational, Playful, Notebook, Kids |
| Psychedelic | Liquid, Rainbow, Organic, Retro |

Guidance: geometric confetti (Memphis), halftone/speech bubbles (Comic/Pop), wobbly borders + marker type (Hand-Drawn/Doodle). Keep motion bouncy, imagery illustrated.
