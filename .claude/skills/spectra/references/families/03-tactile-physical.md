# 3. Tactile & Physical

| Core | Potential modifiers |
| ---- | ------------------- |
| Skeuomorphism | Leather, Paper, Metal, Wood, Glass, Fabric |
| Neumorphism | Soft, Dark, Light, Monochrome, Colored |
| Claymorphism | Pastel, Playful, 3D, Soft, Candy |
| Soft UI | Pastel, Minimal, Dark, Rounded, Organic |
| Material Design | Google-inspired, Expressive, Dense, Colorful, Minimal |
| Paper UI | Notebook, Newspaper, Craft, Academic, Handmade |
| Industrial UI | Metal, Machinery, Technical, Blueprint, Utilitarian |

Guidance: surfaces feel physical — texture, depth, soft/extruded shadows. Keep one material metaphor per project (e.g. leather+metal for premium finance, paper for academic).
